# Contributing to Viral Shorts Video Editor

Thank you for your interest in contributing to **Viral Shorts Video Editor**!  
This project is open-source, maintained by **iwprimo** ([iwprimo@gmail.com](mailto:iwprimo@gmail.com)) under the **MIT License**.

We welcome contributions of all types: bug fixes, performance optimizations, new viral retention components, documentation improvements, and localization.

---

## 📋 Core Architectural Principles

When contributing code, please strictly adhere to the following rules:

### 1. 🚫 Strict Zero-Emoji UI Rule (P0)
- **Rule:** Under no circumstance should Unicode emojis be used in the editor interface (buttons, badges, tabs, menus, modal headers, or tooltips).
- **Standard:** Use modern vector SVG icons from `lucide-react` or `lucide-static` exclusively.
- **Exception:** Emojis are permitted only inside user-facing video subtitles/captions generated by speech processing or keyword highlights.

### 2. 🛡️ Security & Zero Credentials
- **No Secrets in Git:** Never commit API keys, tokens, or credentials.
- **Mandatory Pre-Commit Check:** Always run the automated security auditor before submitting changes:
  ```bash
  npm run security:check
  ```
  This script scans tracked files for known credential patterns and blocks accidental leaks.
- **SSRF Prevention:** Any network fetch must validate destination protocols and restrict hostnames to trusted CDNs.

### 3. 🧹 Clean Code & Pragmatic Standards
- Follow the Single Responsibility Principle (SRP): keep functions concise and well-scoped.
- Keep components typed with TypeScript (`noEmit` verification must pass with 0 errors).
- Preserve existing comments and docstrings unless directly related to your modifications.

## 🛠️ Local Development Setup

1. **Fork and Clone the Repository:**
   ```bash
   git clone https://github.com/iwprimo/editor-video.git
   cd editor-video
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Verify TypeScript & Build:**
   ```bash
   # Validate types across all files
   npm run typecheck

   # Validate production bundle compilation
   npm run build

   # Run 007 Security Audit
   npm run security:check
   ```

## 🔄 Pull Request Guidelines

1. **Branch Naming:**
   - `feat/feature-name` for new capabilities.
   - `fix/bug-description` for bug fixes.
   - `docs/topic` for documentation updates.

2. **Commit Messages:**
   - Use standard conventional commits (e.g., `feat: ...`, `fix: ...`, `docs: ...`, `perf: ...`, `refactor: ...`).

3. **Testing:**
   - Verify both desktop rendering and mobile safe zones preview.
   - Ensure that `npm run typecheck`, `npm run build`, and `npm run security:check` all pass with exit code `0`.
